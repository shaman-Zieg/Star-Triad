# 知人 Zhiren · Star-Triad

**知人**取意于“知人善任”，是一款面向招聘、人才发展和组织协作的 Web 工具。项目把结构化面试、人才九宫格、继任计划、70-20-10 发展计划、组织诊断等人力资源方法，转化为可以直接操作、查看依据和跟进行动的工作流程。

界面支持中文 / English 切换、明暗主题和不同屏幕尺寸。应用使用 Node.js 内置 HTTP 服务与 SQLite，基础功能无需安装第三方依赖；也可按需启用 Claude AI 辅助分析。

## 主要功能

| 模块 | 主要能力 |
| --- | --- |
| 工作台 | 汇总人员、招聘、培训、服务请求和继任覆盖等指标，展示招聘漏斗、部门人数、人员异动与待关注事项。 |
| 智能招聘 | 职位管理、候选人流程、简历匹配与批量筛选、JD 编写与措辞检查、STAR 结构化面试、多面试官评分及录用后的入职计划。 |
| 人才盘点 | 人才九宫格与拖拽校准、胜任力评估、基于个人事实的解读与发展建议、关键岗位继任计划、候选资格检查和流失风险分析。 |
| 培训发展 | 根据能力差距生成 70-20-10 个人发展计划，支持培训需求分析、课程与学员管理、学习行动跟踪及培训效果评估。 |
| 组织诊断 | 六盒模型、7S、敬业度与团队效能问卷，提供匿名调查、维度分析、部门热力图、组织架构、离职分析和 RACI 职责矩阵。 |
| 员工服务 | 员工目录与档案、服务请求分派和跟进、制度知识库、基于制度内容的 HR 助手及 30-60-90 天入职清单。 |
| HR 工具箱 | 汇集常用 HR 方法，提供年假、加班费、薪酬区间、人员流失成本、招聘漏斗、人力规划和 eNPS 等计算工具。 |

分析结果会展示评分依据、能力缺口或风险因素，便于复核。首次启动会生成“星海科技”的演示数据，可直接体验招聘、人才盘点、培训和组织诊断等流程。

### 指标解释、跨岗推荐与留任干预

- 工作台指标卡支持悬浮或键盘聚焦查看名词解释、统计口径和当前数据计算过程。
- 招聘中的高优先级岗位，开放超过 30 天且尚未招满时，会突出开放天数和剩余缺口，并显示最多 3 名跨岗候选人。先检查最低经验、最低学历和全部必备技能，再按简历匹配分排序；已入职、Offer 阶段及原本申请该岗位的人不参与跨岗推荐。候选人不足时如实显示，不自动调岗。
- 培训发展 → 个人发展计划 → 留任干预，可为高风险核心人员创建具体行动计划，调整负责人、截止日期和验收标准，跟踪完成情况。创建资格为在职、流失风险分不低于 55，且绩效不低于 4 或潜力为 3；同一员工不能重复创建进行中的留任计划。
- 培训效果评估默认显示普通发展，可切换至留任评估，记录 30/60/90 天回访反馈、后续行动，以及当日风险、敬业度、在职状态和完成率。风险基线保留创建时的数据；当前风险根据员工档案计算，回访记录不会自动修改员工评估。

## 快速运行

### 1. 准备环境

- 安装 **Node.js 22.13 或更高版本**；项目使用 Node.js 内置的 `node:sqlite`。
- 使用 Git 克隆仓库，或在 GitHub 点击 **Code → Download ZIP** 后解压。

### 2. 启动应用

在终端执行：

```bash
git clone https://github.com/shaman-Zieg/Star-Triad.git
cd Star-Triad/zhiren-hr
npm start
```

如果通过 ZIP 下载，进入解压后的 `zhiren-hr` 目录再执行 `npm start`。

基础功能不需要先执行 `npm install`，也不需要单独安装数据库或构建前端。Windows PowerShell 若提示禁止运行 `npm.ps1`，可使用 `npm.cmd start`。

### 3. 打开浏览器

访问 **[http://127.0.0.1:3200](http://127.0.0.1:3200)**。

首次启动时，应用会创建 `zhiren-hr/data/zhiren.db` 并填入演示数据；后续启动会保留已有修改。保持终端窗口运行，结束使用时按 `Ctrl+C` 停止服务。

## 常用命令

以下命令均在 `zhiren-hr` 目录执行：

| 命令 | 作用 |
| --- | --- |
| `npm start` | 启动应用。 |
| `npm run dev` | 以监听模式启动，后端文件变化后自动重启。 |
| `npm test` | 运行规则引擎、API、AI 流式响应、人才盘点与继任资格等自动化测试。 |
| `npm run reset` | 清除当前应用数据并重新生成演示数据；执行前请备份。 |
| `node --disable-warning=ExperimentalWarning scripts/validate-talent.mjs` | 在数据库副本上生成详细的人才盘点验证报告。 |

## 可选：启用 AI 辅助

当前 AI 集成使用 Anthropic Claude，可辅助生成 JD、候选人分析、面试问题、人才解读、发展建议和组织诊断报告。启用时需要可用的 Anthropic API 凭据及网络连接。

先在 `zhiren-hr` 目录安装可选依赖：

```bash
npm install
```

然后设置环境变量并启动。Windows PowerShell 示例：

```powershell
$env:ANTHROPIC_API_KEY = "你的 API 密钥"
npm start
```

macOS / Linux 示例：

```bash
export ANTHROPIC_API_KEY="你的 API 密钥"
npm start
```

模型由 `ZHIREN_AI_MODEL` 控制，请按账户实际可用的模型设置。没有配置 AI 时，基础规则分析仍可使用。AI 请求会将相关输入发送给 Anthropic，并可能产生 API 费用；密钥请通过环境变量配置。

## 运行配置

以下环境变量需要在启动前设置；当前启动命令不会自动加载 `.env` 文件。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3200` | 服务端口；被占用时可改用其他端口。 |
| `HOST` | `127.0.0.1` | 默认仅本机访问；可信局域网共享时可设为 `0.0.0.0`。 |
| `ZHIREN_DB_PATH` | 应用目录下的 `data/zhiren.db` | 自定义 SQLite 数据库文件路径。 |
| `ZHIREN_DEMO` | 启用 | 设为 `0` 可关闭界面上的演示数据重置功能。 |
| `ANTHROPIC_API_KEY` | 未设置 | 启用 AI 使用的 API 密钥。 |
| `ZHIREN_AI_MODEL` | `claude-opus-5-5` | 代码中配置的默认模型名，可覆盖为账户可用的模型。 |
| `ZHIREN_AI_RPM` | `20` | AI 接口每分钟请求上限。 |
| `ZHIREN_AI` | 启用 | 设为 `0` 可强制关闭 AI，即使已配置凭据。 |

例如，在 Windows PowerShell 中更换端口：

```powershell
$env:PORT = "3201"
npm start
```

此时访问 [http://127.0.0.1:3201](http://127.0.0.1:3201)。

## 数据与使用范围

- 数据保存在本机 SQLite 数据库中。备份前先停止服务，再复制整个 `zhiren-hr/data` 目录；若配置了自定义数据库路径，请备份对应文件及其所在目录中的相关 SQLite 文件。
- 当前版本没有登录认证与角色权限控制。界面中的操作者切换用于记录操作归属，适合本机或可信内网体验；公开部署前需要补充身份认证与访问控制。
- 简历解析支持粘贴纯文本及导入 `.txt`、`.md` 文件；PDF、Word 简历需先转换为文本。
- 内置制度、计算器和人才分析用于演示与辅助判断，实际应用时应结合组织制度、当地适用规则和人工复核。

应用的更多技术说明见 [zhiren-hr/README.md](zhiren-hr/README.md)。
