# 知人 Zhiren 设计规范

本文件是界面的唯一设计依据。改界面前先读这里；新样式优先用这里的变量，不要写新的颜色值或内联样式。

## 1. 产品与使用场景

- **谁在用：** HR 和直线经理，多在工位的显示器上，常常一边开校准会或面谈，一边查数据。
- **要完成什么：** 判断一个人、一个岗位或一个团队的状况，并说得出依据。
- **界面气质：** 冷静、精确、可追溯。像一份有批注的人事档案，而不是营销页面。

## 2. 风格原则

1. **中性底色，宝蓝只表达操作和当前位置。** 大面积是冷灰白；彩色只用来传达状态。
2. **层级靠字重、留白和分隔线，不靠卡片和色块。** 一组同类数据放进一个面板，用细线分隔。
3. **每屏只有一个重点。** 工作台先回答“今天要处理什么”，指标在后。
4. **依据角标是产品的标志。** `.fact` 表示“这个结论有依据”，只用于可追溯的结论。
5. **边框要几乎察觉不到。** 面板不加阴影，阴影只留给浮层（弹窗、菜单、提示）。

明确不做：彩色大块提醒条、图标放在彩色方块里、渐变、玻璃拟态、彩色左边框、全大写小标题。

## 3. 设计变量（`public/css/app.css`）

| 类别 | 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|---|
| 背景 | `--bg` | `#f4f5f7` | `#0f1218` | 页面底色 |
| 面板 | `--surface` | `#ffffff` | `#161a22` | 面板、输入框 |
| 次级面板 | `--surface-2` / `--surface-3` | `#f1f2f5` / `#e5e7ec` | `#1d222c` / `#272d39` | 悬停、标签、看板列 |
| 边框 | `--border` / `--border-strong` | `#e1e3e9` / `#c7cbd4` | `#272d39` / `#3b4354` | 分隔线 / 控件边框 |
| 文字 | `--text` / `--text-2` / `--text-3` | `#161a23` / `#454c5c` / `#626a7a` | `#eceef3` / `#bac1cf` / `#949cac` | 主要 / 次要 / 辅助 |
| 品牌 | `--brand` / `--brand-soft` / `--brand-text` | `#2f56d0` / `#e8edfb` / `#2849b8` | `#3d66e0` / `#18244a` / `#9db6ff` | 主按钮 / 选中 / 链接 |
| 状态 | `--ok` `--warn` `--danger` `--info`，各有 `-soft` 和 `-mark` | | | 文字 / 底色 / 图形 |

正文和占位文字的对比度不低于 4.5:1。图表颜色使用 `--series-*`、`--seq-*`、`--div-*`。

## 4. 字体与字号

- 字体：系统界面字体（Windows 为 Segoe UI 与微软雅黑，macOS 为 SF 与苹方）。不加载中文网页字体，以免增加几 MB 的体积。
- 字号：说明 12–12.5px，正文 14px，面板标题 15px，弹窗标题 16px，页面标题 22px。
- 指标数字 26–28px、字重 600，所有数据使用等宽数字（`font-variant-numeric: tabular-nums`）。

## 5. 间距、圆角与密度

- 间距档位：4、8、12、16、20、24px，对应 `.mt-1`…`.mt-5`、`.mb-2`…`.mb-6`、`.gap-*`。
- 圆角：`--radius-sm` 5px（标签）、`--radius` 7px（控件）、`--radius-lg` 10px（面板、弹窗）。
- 密度：控件高 32px，小按钮 26px，表格行内边距 8px 12px，面板内边距 16px。

## 6. 组件约定

| 组件 | 约定 |
|---|---|
| 表格 | 只有横线，表头 12.5px 辅助色，数字右对齐；可点击的行要有 `tabindex="0"`，回车可打开 |
| 指标 | 同组指标放在一个 `.kpi-strip` 里，不要拆成多张卡片 |
| 提醒列表 | `.attention`：用小圆点表示严重程度，文字保持正文色 |
| 提示框 | `.callout` 只用于解释或确实需要注意的情况，不要连续堆叠 |
| 看板 | 列底色 `--surface-2`，卡片细边框、无阴影 |
| 九宫格 | 高度固定、一屏可比，人多时在格内滚动 |
| 弹窗 | 用于需要打断的确认或短表单；较长的编辑用独立页面（如发展计划） |

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按钮按压（缩放到 0.97） | 120ms | `--ease-out` |
| 悬停颜色变化 | 120ms | `ease` |
| 弹窗、提示进入 | 200ms | `--ease-out` |
| 弹窗退出 | 120ms | `ease` |
| 手机侧边栏 | 240ms | `--ease-drawer` |

规则：只动 `transform`、`opacity` 和颜色；禁止 `transition: all`；页面切换和键盘操作不加动画；加载提示延迟 220ms 才出现，避免闪烁；已适配“减少动态效果”。

## 8. 代码约定

- 项目是原生 JavaScript 模块，不使用 React，不需要构建步骤。
- 静态样式用样式类；只有真正动态的值（进度宽度、图表尺寸）才写内联样式。
- 图标统一用 `core.js` 的 `icon()`，不用 emoji 或特殊字符代替。
- 没有可见标签的输入框要加 `aria-label`；只有图标的按钮也要加。

## 9. 验收清单

- `npm test` 全部通过。
- 主要页面在 390、768、1440 三种宽度下没有横向溢出。
- 中文、英文、浅色、深色都检查过。
- 所有控件都能用键盘操作，并有可见的焦点样式。
